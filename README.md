# MAMÃE FITNESS
PWA pessoal de acompanhamento de treino, alimentação, hidratação e evolução de Edna Viana. Dados de uso ficam somente no navegador/aparelho (localStorage). Meta de água configurada em 3,5 L/dia. O conteúdo do plano foi transcrito dos documentos fornecidos; links do YouTube são apenas conteúdo complementar de demonstração.
